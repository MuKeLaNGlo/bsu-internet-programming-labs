# Лабораторная работа №1 - Портфолио

## Описание
Веб-сайт портфолио, разработанный для курса "Интернет-программирование" БГУ.

## Технологии
- HTML5
- CSS3
- JavaScript (ES6+)

## Функциональность
- Адаптивная навигация
- Анимации при прокрутке
- Интерактивная временная линия опыта работы
- Темная/светлая тема
- Плавная прокрутка к разделам
- Адаптивный дизайн для мобильных устройств

## Структура проекта
```
├── index.html          # Главная страница
├── css/
│   └── style.css      # Стили
├── js/
│   └── script.js      # Интерактивность
└── images/
    └── profile.jpg    # Фото профиля
```
