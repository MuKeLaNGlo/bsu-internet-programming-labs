## Практическая работа №8 - Интернет-магазин

Создайте новые модели и исправьте существующие в соответствии со схемой БД простейшего интернет магазина:
- Метод, возвращающий список товаров, должен позволять получать товары по категориям
- Требуется пагинация для отображения товаров
- Должны быть реализованы методы для получения списка заказов пользователя
- Должна быть доступна возможность получения списка заказанных товаров для каждого заказа
- Для каждой модели должен быть создан роутер и контроллер, позволяющий выполнять CRUD операции

---

## Правила оформления кода и репозитория

### Структура проекта
- Использовать MVC архитектуру с разделением на `models/`, `controllers/`, `routes/`, `middlewares/`, `config/`, `utils/`
- Все исходные файлы располагать в директории `src/`
- Файл базы данных SQLite хранить в директории `data/` (исключена из git)

### Комментарии в коде
- Не использовать эмодзи в коде
- Комментарии писать только на русском языке
- Оставлять только важные комментарии, описывающие сложную логику
- Избегать очевидных комментариев

### Документация
- Создавать `README.md` с описанием проекта, API и примерами использования
- Создавать `TESTING.md` с подробным описанием тестирования
- В `TESTING.md` размещать сводную таблицу результатов в начале файла
- Использовать markdown-таблицы для структурирования информации

### Git
- Использовать осмысленные commit message на русском языке
- Не коммитить файлы баз данных, логов, node_modules
- Правильно настраивать `.gitignore`

### Код
- Использовать `async/await` для асинхронных операций
- Валидировать входные данные
- Обрабатывать ошибки через middleware
- Использовать единый формат ответов API

### База данных
- Для локальной разработки использовать SQLite
- Создавать Promise-обертки над callback-based API
- Реализовывать методы инициализации и миграций
