## Лабораторная работа №8 - Интернет-магазин

### Описание задания

Необходимо доработать приложение (Лабораторная работа №7):

- Создать модели для заказов и товаров в заказе
- Реализовать систему заказов для интернет-магазина
- Добавить пагинацию для списка товаров
- Обеспечить фильтрацию товаров по категориям

### Требования к реализации

**Модели:**
- Создать модель Order (id, user_id, status, total_amount, createdAt, updatedAt)
- Создать модель OrderItem (id, order_id, product_id, quantity, price_at_purchase, createdAt, updatedAt)
- Обновить схему БД с таблицами orders и order_items
- Поддержка внешних ключей и каскадного удаления

**Функциональность товаров:**
- Добавить пагинацию для GET /api/products (параметры: page, limit)
- Фильтрация товаров по category_id уже реализована
- Возвращать информацию о пагинации (currentPage, pageSize, totalItems, totalPages)

**Функциональность заказов:**
- Реализовать CRUD операции для заказов
- GET /api/orders - получить все заказы пользователя
- GET /api/orders/:id - получить заказ по ID
- POST /api/orders - создать новый заказ
- GET /api/orders/:id/items - получить товары заказа
- PATCH /api/orders/:id/status - обновить статус заказа
- DELETE /api/orders/:id - удалить заказ
- Все операции с заказами требуют авторизации
- Пользователь может видеть только свои заказы

**Безопасность и валидация:**
- Проверка наличия товаров на складе при создании заказа
- Фиксация цены товара на момент покупки (price_at_purchase)
- Автоматический расчет общей суммы заказа
- Валидация статусов заказа (pending, processing, completed, cancelled)

### Реализованная функциональность

**Модели данных:**
- Order - заказы пользователей с отслеживанием статуса
- OrderItem - товары в заказе с зафиксированной ценой
- Связь: User → Orders (один-ко-многим)
- Связь: Order → OrderItems (один-ко-многим)
- Связь: Product → OrderItems (один-ко-многим)

**Пагинация:**
- GET /api/products?page=1&limit=10
- Возврат метаданных пагинации
- Работа вместе с фильтрами и сортировкой

**Управление заказами:**
- Создание заказа с несколькими товарами
- Автоматический расчет суммы заказа
- Получение детальной информации о товарах в заказе
- Обновление статуса заказа
- Удаление заказа (каскадное удаление товаров заказа)
