# Лабораторная работа №2

## Задание

Создать сервер, который будет отдавать информацию о товарах.

### Требуемый функционал:

1. **Просмотр списка товаров в JSON** - GET /api/products
2. **Получение товара по ID** - GET /api/products/:id
3. **Добавление товара в каталог** - POST /api/products
4. **Изменение товара по ID** - PUT /api/products/:id
5. **Удаление товара по ID** - DELETE /api/products/:id

### Требования:

- Для сервера достаточно использовать массив (база данных не требуется)
- Приложение разрабатывать с использованием git
- Разместить на GitHub/GitVerse
- В качестве ответа отправить ссылку на репозиторий

### Технологии:

- Node.js
- Express.js (или другой фреймворк)
- Git для версионирования
