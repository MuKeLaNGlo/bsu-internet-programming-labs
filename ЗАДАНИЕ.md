## Лабораторная работа №7 - Восстановление пароля

### Описание задания

Необходимо доработать приложение (Лабораторная работа №6):

- Добавить функциональность восстановления забытого пароля
- Реализовать отправку писем с токеном сброса пароля
- Обеспечить безопасность процесса восстановления

### Требования к реализации

- Добавить поля resetPasswordToken и resetPasswordExpires в модель User
- Обновить схему БД для поддержки токенов восстановления
- Реализовать эндпоинт POST /api/auth/forgot-password для запроса восстановления
- Реализовать эндпоинт POST /api/auth/reset-password для установки нового пароля
- Токены должны иметь ограниченный срок действия (1 час)
- Использовать crypto.randomBytes для генерации токенов
- Хешировать новые пароли перед сохранением
- Очищать токены после использования
- Поддержка работы без настроенного email (вывод токена в консоль)
- Не раскрывать информацию о существовании пользователя в системе

### Реализованная функциональность

**Два варианта восстановления пароля:**

1. **Через email (продакшен):**
   - Пользователь запрашивает восстановление пароля
   - Получает email с токеном и ссылкой
   - Использует токен для установки нового пароля

2. **Через консоль (разработка/тестирование):**
   - При отсутствии настроенного email сервиса
   - Токен выводится в логи сервера
   - Можно скопировать и использовать для тестирования

**Безопасность:**
- Токены действительны только 1 час
- Проверка срока действия при сбросе пароля
- Одноразовое использование токенов (очистка после применения)
- Пароли хешируются с помощью bcrypt
- Унифицированные сообщения об ошибках (не раскрывают наличие пользователя)
