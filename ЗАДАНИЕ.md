# Лабораторная работа №4 - Загрузка файлов и статические ресурсы

## Задание

Необходимо доработать предыдущее приложение (Лабораторная работа №3):
- Настроить загрузку файлов на сервер
- Настроить раздачу статических ресурсов с сервера
- Добавить возможность загрузки изображений для товаров и категорий

## Требования

- Использовать Multer для загрузки файлов
- Настроить валидацию типов файлов (разрешены только изображения)
- Ограничить размер файлов (максимум 5MB)
- Использовать уникальные имена файлов (UUID)
- Настроить Express для раздачи статических файлов
- Добавить поле `image` в БД для товаров и категорий
