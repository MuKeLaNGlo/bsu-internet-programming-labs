# Лабораторная работа №1

## Задание

С помощью HTML, CSS, JS создать страницу портфолио, которая содержит информацию о Вас:

### Требуемые элементы:

1. **Личная информация**
   - Имя
   - Город
   - Возраст
   - Email
   - Фото

2. **Опыт работы**
   - Организации в которых работали
   - Год начала работы
   - Год окончания работы

3. **Стек технологий**
   - Языки программирования
   - Фреймворки
   - Другие технологии

4. **Образование**
   - Что закончили
   - В каком году
   - Курсы повышения квалификации

### Дополнительные требования:

- Данную страницу необходимо развернуть в GitHub Pages

### Технологии:

- HTML
- CSS
- JavaScript
