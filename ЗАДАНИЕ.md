# Лабораторная работа №5 - Авторизация и регистрация

## Задание

Необходимо доработать предыдущее приложение (Лабораторная работа №4):
- Добавить модель User
- Реализовать регистрацию пользователей
- Реализовать авторизацию пользователей

## Требования

- Использовать bcrypt для хеширования паролей
- Использовать JWT для генерации токенов
- Создать таблицу users в БД
- Реализовать эндпоинты POST /api/auth/register и POST /api/auth/login
- Пароли должны храниться в зашифрованном виде
