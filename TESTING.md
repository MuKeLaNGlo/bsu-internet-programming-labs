# Тестирование REST API для управления товарами с категориями

## Описание

Ручное тестирование всех CRUD операций REST API для управления товарами и категориями с использованием SQLite базы данных. Включает тестирование связи один-ко-многим между категориями и товарами.

## Окружение

- Node.js v18+
- SQLite3
- Express.js 4.18.2
- Порт: 3000

## Запуск сервера

```bash
npm start
```

Вывод при успешном запуске:
```
Подключение к SQLite базе данных успешно
Тестовые категории добавлены
Тестовые товары добавлены
Сервер запущен на порту 3000
```

### Реализованные требования Lab 3:

**Данные хранятся в базе данных** - SQLite с персистентностью

**Связь один-ко-многим** - FOREIGN KEY (category_id) REFERENCES categories(id) ON DELETE SET NULL
**Контроллеры реализованы** - categoryController и productController
**CRUD операции для категорий** - все операции работают
**Фильтрация товаров по category_id** - работает корректно
**Валидация данных** - для товаров и категорий
**Обработка ошибок** - валидация, 404, дубликаты

### Дополнительно протестировано:

- Фильтрация по нескольким параметрам
- Обновление связей между таблицами
- Foreign key constraints
- Уникальность имен категорий
- Персистентность после перезапуска

Все функции работают стабильно и корректно.
